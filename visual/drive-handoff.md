# From the rack to the Linux ticket

The paid [Data Center Simulator on Steam](https://store.steampowered.com/app/4535710/) offers first-person technician tickets and component swaps. Pick a hardware ticket and record the component label, the symptom and the check the game asks for. If you want the free route, use the [four-bay exercise](four-bays.md) and record which two bay labels you covered.

Now open the [mirror status lab](../labs/mirror-status.md) in a separate Linux terminal. Compare the healthy and degraded captures. A Linux device name such as vdb1 tells you how the system names a partition. Connecting that name to a physical bay takes separate evidence such as a controller inventory that maps a device identifier to a slot.

**What to show a recruiter.** Put your annotated game screenshot or bay drawing beside your terminal comparison. Caption the first with the physical observation. Caption the second with the active member count before and after. Identify which details came from the game or drawing and which came from the supplied Linux captures. Finish with one sentence explaining what inventory record you would request before identifying a physical drive on a real ticket.
